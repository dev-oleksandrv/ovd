# @ovd/cli

The `ovd` command of OVD (Open Vega DevTools): an unofficial, open-source device toolkit for Vega OS developers. Not affiliated with Amazon. Vega and Fire TV are trademarks of Amazon.

```bash
npm i -g @ovd/cli
ovd --help
```

Requires macOS or Ubuntu, Node.js 22+, and the Vega SDK installed on your machine.

Docs, roadmap and the desktop app: https://github.com/dev-oleksandrv/ovd
